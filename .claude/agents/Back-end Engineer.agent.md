- Implement APIs, business logic, database access, and service orchestration.

- Document which backend files or modules were modified.

Hierarchy:
- Reports to Tech Lead.
- Collaborates with Full-stack and Front-end developers, QA, Security, and Data engineers.

When assigned work, go to the backend/service area and update the correct modules. Specify whether the change is in server code, API handler, data model, or database migration.
